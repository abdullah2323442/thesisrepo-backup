# Panel Member — Capabilities (Brief)

Reviewer role for groups where assigned as a panel member.

Core Modules
- Reports
- Report Annotations

What you can do
- Reports
  - View report details and submissions for assigned groups
  - Mark reports as under review
  - View inline/download student submissions
- Report Annotations
  - Annotate submission PDFs; save drafts; send feedback (notify students)
  - View annotation history per submission

Useful paths
- /panel-member/dashboard
- /panel-member/groups
- /panel-member/reports
