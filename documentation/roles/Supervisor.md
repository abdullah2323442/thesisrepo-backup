# Supervisor — Capabilities (Brief)

Main supervisor for groups; manages meetings, reports, and approvals.

Core Modules
- Groups (visibility + permissions)
- Meetings
- Reports
- Report Annotations

What you can do
- Groups
  - View groups where you are main/co/panel; toggle co-supervisor meeting permissions per group
- Meetings
  - Create/view/edit meetings for groups you can manage
  - Filter by group/date; fetch group students (JSON)
  - Export a group’s meetings as PDF (attendance included)
- Reports
  - Create/view/edit/delete; mark under review
  - Finalize and approve final reports (publish to public repository)
  - View inline/download student submissions
- Report Annotations
  - Annotate submission PDFs; save drafts; send feedback (notify students)
  - View annotation history per submission

Useful paths
- /supervisor/dashboard
- /supervisor/groups
- /supervisor/meetings
- /supervisor/reports
