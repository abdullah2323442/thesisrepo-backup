# Student — Capabilities (Brief)

End-user thesis participant with group, report, and meetings access.

Core Modules
- Dashboard & Meetings
- Reports
- Submissions
- Annotations (Read-only)
- Notifications

What you can do
- Dashboard & Meetings
  - See group name/members, AOIs, supervisor info; view meeting history
- Reports
  - View list and details; see comments and approval status (badges)
- Submissions
  - Create one submission per report; edit/delete your own; download your file
  - Allowed types: PDF/PPT/PPTX; max size 20MB
- Annotations
  - View your submission’s annotation history; download annotated sessions when available
- Notifications
  - Bell dropdown (latest 10) + full history; mark one/all as read

Useful paths
- /student/dashboard
- /student/meetings
- /student/reports
- /student/notifications
