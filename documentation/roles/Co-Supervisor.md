# Co‑Supervisor — Capabilities (Brief)

Reviewer/co-manager on assigned groups; limited meeting management when permitted.

Core Modules
- Meetings (with permission)
- Reports
- Report Annotations

What you can do
- Meetings
  - Create/edit meetings only if the main supervisor enabled permission for that group
- Reports
  - View details and submissions; mark under review
  - View inline/download student submissions
- Report Annotations
  - Annotate submission PDFs; save drafts; send feedback (notify students)
  - View annotation history per submission

Useful paths
- /co-supervisor/dashboard
- /co-supervisor/groups
- /co-supervisor/meetings
- /co-supervisor/reports
